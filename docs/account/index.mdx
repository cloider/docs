The account pages cover everything around your resources: who can reach the account, the tokens tools use, what the account costs, its invoices, the messages Cloider sends you, and how to get help.

## At a glance

| Task | Where in the dashboard | CLI | Page |
| --- | --- | --- | --- |
| Invite members, change roles | **Access Control**, **Members** | `cloider member list` (read only) | [Access control](/account/access-control) |
| Create and revoke API tokens | **Access Control**, **API Tokens** | `cloider token list` (read only), `cloider login`, `cloider logout` | [API tokens](/account/api-tokens) |
| Work in another account | Account menu, **Switch account** | `cloider login --profile`, `cloider profile use` | [Switch accounts](/account/switch-accounts) |
| See this month's costs and forecast | **Usage** | `cloider usage` | [Usage](/account/usage) |
| Read invoices (Owner only) | **Billing** | `cloider billing` | [Billing](/account/billing) |
| Read announcements | Bell icon, **Notifications** | | [Notifications](/account/notifications) |
| Get help from the Cloider team | **Support** | `cloider support` | [Support](/account/support) |

## Access Control in the dashboard

**Access Control** in the sidebar groups every kind of access to the account in tabs:

| Tab | What it holds | Docs |
| --- | --- | --- |
| **Members** | The Owner and every invited member, with their role and status | [Access control](/account/access-control) |
| **S3 Credentials** | Access keys for S3 tools to reach your buckets | [Access keys](/object-storage/access-keys) |
| **Registry Tokens** | Tokens for `docker login` and Kubernetes pull secrets | [Registry tokens](/container-registry/tokens) |
| **API Tokens** | Tokens for the CLI, Terraform, the MCP server and the REST API | [API tokens](/account/api-tokens) |

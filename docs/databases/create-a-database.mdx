This page shows how to create a managed database on Cloider with each of the five tools, what every setting means, which names are allowed, and how to fix the errors you can get. A new database is usually ready to accept connections a few minutes after you create it.

## Before you begin

- You need a Cloider account. See [create an account](/get-started/create-an-account).
- Your role in the account must allow changes. Members with read-only access can't create databases, see [access control](/account/access-control).
- For the CLI, [install the CLI](/cli/install) and run `cloider login`.
- For Terraform, the REST API and the CLI in CI, create an [API token](/account/api-tokens) with Read & Write access.
- For MCP, [set up the MCP server](/mcp/setup) in your AI client.
- On the free plan, an account can have one database at a time. See [billing](/account/billing).

## What you choose when you create a database

| Setting | What it is | Can it change later? |
| --- | --- | --- |
| **Name** | The database's name. It is the name of the database inside the engine (for PostgreSQL, MySQL and MongoDB) and part of its host name, `<name>-<id>.db.cloider.com` | No |
| **Username** | The user your application connects as. The password is generated for you | No |
| **Engine and version** | PostgreSQL 18, MySQL 9, MongoDB 8 or Redis 8. See [which engine to choose](/databases/overview#which-database-engine-should-i-choose) | No |
| **Trusted sources** | Who may connect: anywhere, IPv4 addresses or ranges, your apps, your clusters. See [trusted sources](/databases/trusted-sources) | Yes, any time |
| **SSL mode** | Whether connections use TLS. See [SSL/TLS](/databases/ssl-tls) | Yes, with a short restart |
| **Plan** | CPU, RAM and storage. See [plans and sizes](/databases/overview#plans-and-sizes) | Yes, to a larger plan only. See [resize](/databases/resize) |

The database also gets a **label**, the name it is shown and found by in the dashboard and the CLI. The label starts as the name, and gets a `-1`, `-2` and so on suffix when another database in the account already has that label. You can [rename](#how-do-i-rename-a-database) a database's label at any time.

## Create a database

<Tabs groupId="interface" queryString>
<TabItem value="dashboard" label="Dashboard" default>

1. Open **Databases** in the sidebar and click **Create Database**.
2. In **Database Name**, type a name, for example `orders-db`.
3. **Database Username** fills itself in from the name (`orders_db_user`). Change it if you want another user name.
4. In **Database Engine**, choose the engine and version, for example **PostgreSQL v18**.
5. In **Trusted sources**, keep **Allow Everything** or choose who may connect: **Allow My IP**, one of your clusters or apps, or type an IPv4 range in CIDR format such as `203.0.113.0/24` and press Enter.
6. Leave **SSL Mode** on to require encrypted connections. It is on by default for PostgreSQL, MySQL and MongoDB, and off for Redis.
7. Under **Select a Plan**, pick a plan. The table shows each plan's monthly and hourly price, RAM, CPUs and storage.
8. Click **Create database**.

The dashboard takes you back to the Databases list, where the new database is highlighted with the status **Creating**. The status changes to **Ready** on its own, and the name becomes a link to the database's page.

</TabItem>
<TabItem value="cli" label="CLI">

```bash
cloider db create orders-db --engine postgresql --plan standard --wait
```

```text title="Output"
✓ Creating PostgreSQL 18 database orders-db (plan Standard)
✓ Database orders-db is ready. Connect with `cloider db connect orders-db`.
```

Without `--wait`, the command returns as soon as the database is being created, and you can follow it with `cloider db status orders-db`.

More examples:

```bash
# MySQL on the Hobby plan (the default plan), only reachable from your current IP
cloider db create shop-db --engine mysql --allow-my-ip

# MongoDB with a custom user, reachable from an office network and one CI runner
cloider db create catalog-db --engine mongodb --plan basic --user catalog_app \
  --trusted-source 203.0.113.0/24 --trusted-source 198.51.100.7

# Redis reachable only from the app "web" and the cluster "production", over TLS
cloider db create cache --engine redis --plan starter --ssl \
  --trusted-source app:web --trusted-source cluster:production --wait

# Print only the new database's id, for scripts
cloider db create orders-db --engine postgresql -q
```

| Flag | Meaning | Default |
| --- | --- | --- |
| `--engine` | `postgresql` (or `postgres`, `pg`), `mysql`, `mongodb` (or `mongo`), `redis`. Required | |
| `--version` | Engine version | The newest offered |
| `--plan` | `hobby`, `starter`, `basic`, `standard`, `plus` or `pro`, in any letter case | `Hobby` |
| `--user` | Database user | `<name>_user`, with `-` turned into `_` |
| `--ssl` / `--no-ssl` | Require TLS, or don't | On, except for Redis |
| `--trusted-source` | `*`, an IPv4 address or CIDR, `cluster:<name>` or `app:<name>`. Repeatable | `*` (anywhere) |
| `--allow-my-ip` | Also trust the public IPv4 address this command runs from | |
| `--wait`, `-w` | Wait until the database is `Ready` | |
| `--timeout` | How long `--wait` waits | `15m` |

</TabItem>
<TabItem value="terraform" label="Terraform">

```hcl title="main.tf"
resource "cloider_database" "orders" {
  name   = "orders-db"
  engine = "postgresql"
  plan   = "standard"

  # Who may connect. Defaults to ["*"], anywhere.
  trusted_sources = [
    "203.0.113.0/24",
    "cluster:${cloider_cluster.production.id}",
  ]

  lifecycle {
    prevent_destroy = true
  }
}

output "orders_db_host" {
  value = cloider_database.orders.host
}

output "orders_db_private_host" {
  value = cloider_database.orders.private_host
}

output "orders_db_port" {
  value = cloider_database.orders.port
}

output "orders_db_password" {
  value     = cloider_database.orders.password
  sensitive = true
}
```

```bash
terraform apply
```

`terraform apply` waits until the database is `Ready` (up to 20 minutes by default, see `timeouts`). The `password` and `ca_certificate` attributes are stored in your Terraform state, so keep the state private.

Attributes you can set: `name` and `engine` (required), `plan` (default `hobby`), `version` (default the newest), `user` (default `<name>_user`), `label`, `ssl` (default on, except for Redis), `trusted_sources` (default `["*"]`, at least one), `paused` and `timeouts`. Changing `name`, `engine`, `version` or `user`, or choosing a smaller plan, replaces the database and its data. See the [`cloider_database` reference](/terraform/resources/database).

</TabItem>
<TabItem value="api" label="API">

```bash
curl -X POST https://cloider.com/api/databases \
  -H "Authorization: Bearer $CLOIDER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "database_name": "orders-db",
    "database_user": "orders_db_user",
    "service": "PostgreSQL",
    "database_version": "18",
    "database_plan": "Standard",
    "trusted_sources": [
      {"name": "Allow Everything", "code": "*", "type": "Anywhere"}
    ],
    "ssl": true
  }'
```

```json title="Response"
{"hashed_id": "p0q9zm"}
```

| Field | Values |
| --- | --- |
| `database_name` | The name, see [naming rules](#naming-rules) |
| `database_user` | The user, see [naming rules](#naming-rules) |
| `service` | `PostgreSQL`, `MySQL`, `MongoDB` or `Redis` |
| `database_version` | `18` for PostgreSQL, `9` for MySQL, `8` for MongoDB and Redis |
| `database_plan` | `Hobby`, `Starter`, `Basic`, `Standard`, `Plus` or `Pro`, capitalized |
| `trusted_sources` | A list of sources, see [the source format](/databases/trusted-sources). An empty or missing list leaves the database unreachable |
| `ssl` | `true` to require TLS. Missing means `false` |

The database is created in the background. Poll its status until it is `Ready`:

```bash
curl https://cloider.com/api/databases/p0q9zm/status \
  -H "Authorization: Bearer $CLOIDER_TOKEN"
```

```text title="Response"
Ready
```

## What happens after you create a database?

Cloider provisions the database in the background. Its status goes through these steps:

1. **`Creating`**: Cloider creates the database server, its storage volume, the user and password, the TLS certificate (when SSL is on), the public and private endpoints and the firewall rules for your trusted sources.
2. **`Ready`**: the database accepts connections. Its page in the dashboard opens, and the Terminal tab appears.

Creation usually takes a few minutes. The first backup is taken on the next daily backup run, so the Backups tab says "You can restore a backup after the first backup is completed." until then.

## Verify

Check that the status is `Ready`:

```bash
cloider db status orders-db
```

```text title="Output"
Ready
```

Then show the connection details and run a first query without installing anything:

```bash
cloider db get orders-db
cloider db exec orders-db "SELECT current_database(), current_user;"
```

```text title="Output"
 current_database |  current_user
------------------+----------------
 orders-db        | orders_db_user
(1 row)
```

## Naming rules

The name and the user are checked when you create the database. Both can't be changed afterwards.

### Database name rules

- 2 to 64 characters.
- Lower case letters (`a` to `z`), digits and hyphens (`-`) only. No spaces, upper case letters or other characters.
- Starts with a letter (not a digit, not a hyphen) and doesn't end with a hyphen.
- Not a reserved name: `mysql`, `information_schema`, `performance_schema`, `sys`, `postgres`, `template0`, `template1`, `admin`, `local` or `config`.

Names don't have to be unique: two databases can share a name, and they are told apart by their id and label. The name is part of the host name, so a short name is easier to type.

:::tip[Hyphens in SQL]
A name with a hyphen, such as `orders-db`, works as is in connection strings and client flags (`psql -d orders-db`). Inside SQL, quote it: `"orders-db"` in PostgreSQL and `` `shop-db` `` in MySQL.
:::

### Username rules

- 2 to 64 characters.
- Lower case letters, digits and underscores (`_`) only. Hyphens aren't allowed.
- Starts with a letter and doesn't end with an underscore.
- Not a reserved user: `root`, `mysql`, `postgres` or `admin`.

The dashboard, CLI and Terraform suggest `<name>_user`, with hyphens turned into underscores: `orders-db` gets `orders_db_user`.

### Label rules

The label follows the database name rules (2 to 64 lower case letters, digits and hyphens, starting with a letter), without the reserved names, and it must be unique among the account's databases.

## Defaults by tool

The tools pick slightly different defaults when you leave a setting out:

| Setting | Dashboard | CLI | Terraform | API | MCP |
| --- | --- | --- | --- | --- | --- |
| Plan | Hobby | Hobby | `hobby` | Required | Hobby |
| Version | The one listed | The newest | The newest | Required | The newest |
| User | `<name>_user` | `<name>_user` | `<name>_user` | Required | `<name>_user` |
| SSL | On, except Redis | On, except Redis | On, except Redis | Off | On, except Redis |
| Trusted sources | Allow Everything | `*` | `["*"]` | None (unreachable) | `*` |

## How do I rename a database?

You can change a database's label, the name it is shown and found by, without touching its host, user or database name.

<Tabs groupId="interface" queryString>
<TabItem value="dashboard" label="Dashboard" default>

1. Open the database's page.
2. Click its name in the breadcrumb at the top, type the new label and confirm.

</TabItem>
<TabItem value="cli" label="CLI">

```bash
cloider db rename orders-db orders-production
```

```text title="Output"
✓ Renamed orders-db to orders-production
```

</TabItem>
<TabItem value="terraform" label="Terraform">

Set `label`:

```hcl title="main.tf"
resource "cloider_database" "orders" {
  name   = "orders-db"
  engine = "postgresql"
  label  = "orders-production"
}
```

</TabItem>
<TabItem value="api" label="API">

```bash
curl -X PUT https://cloider.com/api/databases/p0q9zm/label \
  -H "Authorization: Bearer $CLOIDER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"database_label": "orders-production"}'
```

```json title="Response"
{"success": true}
```

</TabItem>
<TabItem value="mcp" label="MCP">

```text title="Prompt"
Rename the database orders-db to orders-production.
```

```json title="Tool call: rename_database"
{"database": "orders-db", "new_name": "orders-production"}
```

</TabItem>

## Troubleshooting

### Database name must not have special characters except "-"

The name contains a character other than lower case letters, digits and hyphens, for example an underscore or a dot. Use hyphens: `orders-db`, not `orders_db`. The other name errors are just as literal: `Database name can not be upper case`, `Database name can not start with numbers`, `Database name must not have spaces`, `Database name must be at least 2 characters`, `Database name must not exceed 64 characters` and `Database name is reserved`.

### Database username must not have special characters except "_"

The user contains a hyphen or another character. Use underscores: `orders_db_user`. Other user errors: `Database username can not be upper case`, `Database username can not start with numbers`, `Database username must not start with any special character`, `Database username must not end with any special character` and `Database username is reserved` (for `root`, `mysql`, `postgres` and `admin`).

### Invalid database version!

The version doesn't exist for the engine. PostgreSQL takes `18`, MySQL `9`, MongoDB and Redis `8`. In the CLI, leave `--version` out to get the newest.

### Invalid database plan

The plan isn't one of `Hobby`, `Starter`, `Basic`, `Standard`, `Plus` or `Pro`. The API expects the capitalized name. The CLI and Terraform accept lower case.

### database engine must be selected!

The request has no `service`. In the dashboard, choose an option in **Database Engine**.

### This database engine isn't available at the moment!

The engine can't be created right now. `cloider pricing` lists the engines that can.

### Free plan users can not create more than one database. UPGRADE NOW!

Accounts on the free plan can have one database at a time. Delete the existing one or upgrade, see [billing](/account/billing).

### You have read-only access to this account, you can not create databases!

Your role in the account, or your API token, is read-only. Ask an account owner for a role that can make changes, or use a Read & Write token.

### Your account is suspended. Upgrade to a paid plan to continue using our services.

The account is suspended, for example after the trial ended. See [billing](/account/billing).

### The database stays in Creating

Creating usually takes a few minutes. If it is still `Creating` after 20 minutes, [contact support](/account/support) with the database's id (`cloider db list -o wide` shows it).

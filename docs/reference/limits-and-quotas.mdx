This page lists the limits Cloider enforces, grouped by area, with the error you get when you reach one. Limits that apply to one product only are also explained on that product's pages.

## At a glance

| Limit | Value |
| --- | --- |
| API rate limit | 10 requests a second and 100 a minute, per client |
| Trial | 1 cluster, 1 database, 1 bucket, 1 registry project at a time |
| API tokens per account | 50 |
| S3 access keys per account | 50 |
| Registry tokens per account | 50 |
| App upload | 2000 files, 100 MB |
| Dashboard file upload to a bucket | 5 GB per file |
| Support attachments | 5 files of 10 MB per message |

## Rate limits

The API allows **10 requests a second and 100 requests a minute per client**. Requests over the limit are refused with HTTP `429 Too Many Requests` (or sometimes `503 Service Unavailable`).

- The `cloider` CLI, and so the MCP server, retries a refused request up to 3 more times, waiting as long as the `Retry-After` header says (up to 60 seconds) or 1, 2 and 4 seconds otherwise. Reads are also retried on `502`, `503` and `504`; writes are not, since they may have gone through.
- Your own code should do the same: back off on `429` and respect `Retry-After`.

See [Rate limits](/api/rate-limits).

## Trial limits

While an account is on the free trial (the **Free** plan), it can have at most one of each of these at a time. Deleted resources don't count.

| Resource | Limit | Error |
| --- | --- | --- |
| Kubernetes clusters | 1 | `Free plan users can not create more than one cluster. UPGRADE NOW!` |
| Databases | 1 | `Free plan users can not create more than one database. UPGRADE NOW!` |
| Buckets | 1 | `Free plan users can not create more than one bucket. UPGRADE NOW!` |
| Registry projects | 1, not counting the apps project Cloider creates | `Free plan users can not create more than one project. UPGRADE NOW!` |

The trial lasts 14 days. A suspended account can't create resources: `Your account is suspended. Upgrade to a paid plan to continue using our services.`

## Names

Names are lowercase. Where a rule says "letters", it means `a` to `z`.

| Resource | Rules | Unique |
| --- | --- | --- |
| **Cluster** | Letters, digits and `-`; starts with a letter; doesn't start or end with `-`; at least 2 characters | No, the label gets `-1`, `-2`... |
| **App** | Letters, digits and `-`; starts with a letter; doesn't start or end with `-`; 2 to 64 characters | No, the label gets `-1`, `-2`... |
| **Database name** | Letters, digits and `-`; starts with a letter; doesn't start or end with `-`; 2 to 64 characters. Reserved: `mysql`, `information_schema`, `performance_schema`, `sys`, `postgres`, `template0`, `template1`, `admin`, `local`, `config` | No, the label gets `-1`, `-2`... |
| **Database username** | Letters, digits and `_`; starts with a letter; doesn't start or end with `_`; 2 to 64 characters. Reserved: `root`, `mysql`, `postgres`, `admin` | |
| **Database label** | Letters, digits and `-`; starts with a letter; 2 to 64 characters | |
| **Bucket** | Letters, digits and `-`; starts and ends with a letter or digit; 3 to 63 characters; no dots. Reserved: the prefixes `xn--`, `sthree-`, `amzn-s3-demo-`, the suffixes `-s3alias`, `--ol-s3`, `--x-s3`, `--table-s3`, and the name `filemeta` | Across all of Cloider |
| **Registry project** | Letters, digits and `-`; starts and ends with a letter or digit; no `--`; at least one letter; 3 to 63 characters. Reserved: `library` and names starting with `cloider` | Across all of Cloider |
| **Free subdomain label** | Up to 63 characters | Across all of Cloider |
| **Domain name** | Up to 253 characters, each label up to 63 | Across all of Cloider |
| **Environment variable** | Starts with a letter or `_`, then letters, digits and `_` (uppercase allowed); up to 128 characters | Per app |

The exact messages, such as `Cluster name can not start with numbers` or `Bucket name must not exceed 63 characters`, name the rule that failed.

## Kubernetes clusters

| Limit | Value |
| --- | --- |
| Kubernetes versions | The versions `GET /api/options` lists (currently 1.34, 1.33 and 1.32) |
| Upgrades | A cluster keeps its version; create a new cluster for a newer one |
| Ingress | Ingress objects in a cluster are not served; use targets or `LoadBalancer` Services |
| Target to a cluster service | The service name, namespace and cluster name together must fit in a 63 character DNS label: `Service and namespace names are too long for this cluster (combined limit exceeded)` |

| Plans | Hobby, Starter, Basic, Standard, Plus, Pro, each with fixed CPU, RAM and storage |

## Object storage

| Limit | Value | Error |
| --- | --- | --- |
| Dashboard upload | 5 GB per file | `Files over 5 GB can't be uploaded from the dashboard, use an S3 client!` |
| Delete from the dashboard | 1000 files and folders per request | `Too many files at once, select fewer!` |
| Delete a folder from the dashboard | Up to 10000 files | `The folder "<name>" holds over 10000 files, delete it with an S3 client!` |
| Restore a version from the dashboard | 5 GB | `Versions over 5 GB can't be restored from the dashboard, use an S3 client!` |
| Versions listed per file | The newest 1000 | |
| Lifecycle rules | 100 per bucket; prefixes up to 1024 characters; day counts 1 to 36500 | `A bucket can have up to 100 lifecycle rules` |
| Bucket policy | 16 KB of text | `The policy is over 16 KB` |

S3 clients have no dashboard limits: use one for large files and bulk operations. See [S3 tools](/object-storage/s3-tools).

| Limit | Value | Error |
| --- | --- | --- |

| DNS record types | A, AAAA, CNAME, ALIAS, MX, TXT, NS, CAA, HTTPS, SPF, SRV, PTR | |

## Running commands (exec)

| Limit | Value | Error |
| --- | --- | --- |
| Timeout | 1 second to 1 hour; 600 seconds by default | `The timeout can be an hour at most!` |
| Standard input | 2 MiB | `stdin is bigger than 2 MiB!` |
| Command line | 64 KiB | |

Exec isn't available to Restricted members (`You have read-only access to this account, you can not run commands!`) or with a Read token (`This API token is read only!`).

| Limit | Value | Error |

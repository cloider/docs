These pages take you from a new Cloider account to your first running app and Kubernetes cluster, one step at a time. Read them in order if you are new to Cloider, or jump to the page you need.

If you only have five minutes, the [Quick start](/quick-start) does the whole path on one page.

## At a glance

| Step | Page | What you get |
| --- | --- | --- |
| 1 | [Create an account](/get-started/create-an-account) | A Cloider account on the 14-day free trial, signed in with Google or GitHub |
| 2 | [Dashboard tour](/get-started/dashboard-tour) | The sidebar, search, account menu and notifications explained |
| 3 | [Choose a tool](/get-started/choose-a-tool) | When to use the dashboard, the CLI, Terraform, the REST API or an AI agent |
| 4 | [Deploy your first app](/get-started/deploy-your-first-app) | A web app running on a free `cloider.app` subdomain with HTTPS |
| 5 | [Create your first cluster](/get-started/create-your-first-cluster) | A serverless Kubernetes cluster, `kubectl` connected, a workload on the internet |
| 6 | [Install the CLI](/get-started/install-the-cli) | The `cloider` command on your computer, logged in to your account |

## What you can build on Cloider

Cloider is a pay-as-you-go cloud platform. Everything is managed from the same account:

<Cards cols={3}>
  <Card title="Apps" href="/apps/overview" icon="rocket-launch-outline">Deploy code from Git or your computer. No Dockerfile or servers to manage.</Card>
  <Card title="Kubernetes" href="/kubernetes/overview" icon="kubernetes">Serverless clusters with a standard Kubernetes API, billed by usage.</Card>
  <Card title="Databases" href="/databases/overview" icon="database-outline">Managed PostgreSQL, MySQL, MongoDB and Redis with daily backups.</Card>
  <Card title="Object Storage" href="/object-storage/overview" icon="pail-outline">S3 compatible buckets for files, assets and backups.</Card>
  <Card title="Container Registry" href="/container-registry/overview" icon="docker">Private projects for your container images.</Card>
  <Card title="Domains and DNS" href="/domains/overview" icon="web">Free subdomains, your own domains, DNS records and routing.</Card>
</Cards>

## Tools you can use

Every product can be managed from more than one tool. Most people start with the dashboard and add the CLI later.

<Cards cols={3}>
  <Card title="Dashboard" href="/get-started/dashboard-tour" icon="compass-outline">The web interface at cloider.com/dashboard.</Card>
  <Card title="CLI" href="/cli/overview" icon="console">The cloider command for terminals, scripts and CI.</Card>
  <Card title="Terraform" href="/terraform/overview" icon="terraform">Infrastructure as code with the cloider/cloider provider.</Card>
  <Card title="REST API" href="/api/overview" icon="api">HTTP endpoints, authenticated with an API token.</Card>
  <Card title="MCP" href="/mcp/overview" icon="robot-outline">Let an AI agent such as Claude Code or Cursor manage Cloider.</Card>
</Cards>

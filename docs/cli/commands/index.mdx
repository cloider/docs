This page lists every command of the `cloider` CLI, grouped by product, with a one line description and a link to its full reference with flags, examples and output. The CLI has 196 commands and subcommands; `cloider <command> --help` shows the same information in the terminal.

## How to read the reference

Every command page uses the same conventions:

| Notation | Meaning |
| --- | --- |
| `cloider cluster create <name>` | `<name>` is a required argument |
| `cloider cluster services [cluster]` | `[cluster]` is optional |
| `<path>...` or `--trusted-source` (repeatable) | The argument or flag can be given several times |
| `on\|off`, `public\|private` | Pick one of the values |
| `[--]` | A `--` may separate cloider's flags from a remote command's own arguments (exec commands) |
| `<cluster>`, `<database>`, `<app>` | A resource's name, label or id, see [how commands find a resource](/cli/output-and-scripting#how-do-commands-find-a-resource) |

Commands that change a resource take `--wait` (`-w`) and `--timeout`; deletes ask for confirmation unless you pass `--yes`. Every command also takes the [global flags](/cli/configuration#global-flags):

| Global flag | Description |
| --- | --- |
| `--profile <name>` | Profile to use (env `CLOIDER_PROFILE`) |
| `--api-url <url>` | API to talk to (env `CLOIDER_API_URL`, default `https://cloider.com/api`) |
| `--token-file <path>` | Read the API token from this file (env `CLOIDER_TOKEN_FILE`) |
| `-o, --output <format>` | `table`, `wide` (adds ids), `json` or `yaml` |
| `-q, --quiet` | Print only ids or names |
| `--no-headers` | Print tables without the header row |
| `--no-color` | Disable colors (env `NO_COLOR`) |
| `-y, --yes` | Don't ask for confirmation |
| `--debug` | Log API requests to stderr |
| `-h, --help` | Help for any command |

## Commands that work without logging in

`cloider pricing`, `cloider version`, `cloider update` (and its subcommands), `cloider completion`, `cloider profile` and `cloider login` itself work without an API token. Everything else needs one; see [Authentication](/cli/authentication).

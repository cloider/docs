The guides are complete, realistic projects that you build from start to finish on Cloider. Each one ties several
products together (an app and its database, a cluster and its registry, a pipeline and its domain), explains every
step for someone who has never done it before, and gives you complete files to copy. Every guide ends with cleanup
steps, so you only pay for what you keep.

If you are new to Cloider, do the [quick start](/quick-start) first: it takes five minutes and gets you an account,
the CLI and a first app. The product sections ([Apps](/apps/overview), [Kubernetes](/kubernetes/overview),
[Databases](/databases/overview), [Object Storage](/object-storage/overview),
[Container Registry](/container-registry/overview), [Domains and DNS](/domains/overview)) are the reference the guides
link to for details.

## What every guide includes

Every guide follows the same structure, so you always know where to look:

1. **What you'll build**, with an architecture diagram, so you see the end result before you start.
2. **Before you begin**: the accounts, tools and knowledge you need, with links to install them.
3. **Numbered parts**, each ending with a **Verify** step that tells you how to check it worked before you move on.
4. **What it costs**: how each resource in the guide is billed. Prices aren't repeated in the guides; see
   [Pricing](/reference/pricing) and the [billing model](/concepts/billing-model).
5. **Clean up**: the commands that delete everything the guide created.
6. **Troubleshooting** for the errors people actually hit, and **Next steps**.

## Before you start any guide

Most guides use the `cloider` command line tool, because a command is easier to follow and to repeat than a series of
clicks. The dashboard can do every step too, and the guides point to it where it is the natural choice.

```bash
# Install the CLI (macOS and Linux) and log in through your browser
curl -fsSL https://cloider.com/install.sh | sh
cloider login
cloider whoami
```

See [Install the CLI](/get-started/install-the-cli) for Windows and other options, and [Choose a tool](/get-started/choose-a-tool)
for when to use the dashboard, the CLI, Terraform, the API or an AI agent.

:::note[Free trial limits]
A new account starts on a 14-day trial with free credit, and can hold one Kubernetes cluster, one database, one bucket
and one registry project at a time. Most guides fit in that. The guides that need more say so at the start, and the
cleanup steps free the slots again. See [the billing model](/concepts/billing-model).
:::

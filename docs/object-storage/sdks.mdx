Your code reaches Cloider buckets with the official AWS SDKs, because the buckets speak the S3 API. You configure the S3 client with Cloider's endpoint, the region `eu-central-2`, an access key and one checksum setting, and every S3 call (upload, download, list, delete, presign) works as it does on Amazon S3.

This page has a complete, runnable example for each language, then shows the patterns most apps need: large uploads, presigned URLs for downloads and browser uploads, and configuration through environment variables.

## Before you begin

- A bucket, here `acme-assets`. See [Create a bucket](/object-storage/create-a-bucket).
- An [access key](/object-storage/access-keys) for it, read and write if your code uploads or deletes.
- The key in your app's environment, never in the source code:

```bash title=".env"
AWS_ACCESS_KEY_ID=CLDRZ8Q4M2X7KD1PLW0B
AWS_SECRET_ACCESS_KEY=7hT2kV9qWm4LxR8zNc3PbY6sJd1FgA5eUo0iKlMn
AWS_REGION=eu-central-2
AWS_ENDPOINT_URL_S3=https://s3.eu-central-2.cloider.com
AWS_REQUEST_CHECKSUM_CALCULATION=when_required
AWS_RESPONSE_CHECKSUM_VALIDATION=when_required
S3_BUCKET=acme-assets
```

## The four settings every SDK needs

| Setting | Value | Why |
| --- | --- | --- |
| Endpoint | `https://s3.eu-central-2.cloider.com` | Sends requests to Cloider instead of AWS |
| Region | `eu-central-2` | The region requests are signed for |
| Credentials | access key id and secret key | Signs every request |
| Checksum calculation | `when_required` | AWS SDKs released since January 2025 add a checksum to every upload by default, which Cloider's storage doesn't accept. `when_required` sends one only where the S3 API requires it |

Path style addressing is optional: Cloider serves both `https://acme-assets.s3.eu-central-2.cloider.com/key` and `https://s3.eu-central-2.cloider.com/acme-assets/key`. The examples set it explicitly so you can see where the switch is. Older SDK versions that don't know the checksum settings don't send the default checksums either, so for them you can leave the setting out.

:::tip[Configuration from the environment only]
Recent versions of every AWS SDK read `AWS_ENDPOINT_URL_S3`, `AWS_REGION`, the credentials and `AWS_REQUEST_CHECKSUM_CALCULATION` from the environment. With the `.env` above, a client created with no options at all (`new S3Client({})`, `boto3.client("s3")`) talks to Cloider. The explicit examples below work with every SDK version that supports the settings, and make the configuration visible in code.
:::

Install the AWS SDK for JavaScript v3:

```bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner @aws-sdk/lib-storage
```

```js title="s3.mjs"
import {
  S3Client,
  PutObjectCommand,
  GetObjectCommand,
  ListObjectsV2Command,
  DeleteObjectCommand,
} from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { readFile } from "node:fs/promises";

const s3 = new S3Client({
  region: "eu-central-2",
  endpoint: "https://s3.eu-central-2.cloider.com",
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
  },
  forcePathStyle: false, // true works too
  requestChecksumCalculation: "WHEN_REQUIRED",
  responseChecksumValidation: "WHEN_REQUIRED",
});

const Bucket = "acme-assets";

// Upload
await s3.send(new PutObjectCommand({
  Bucket,
  Key: "images/logo.png",
  Body: await readFile("./logo.png"),
  ContentType: "image/png",
  CacheControl: "public, max-age=86400",
}));

// List
const list = await s3.send(new ListObjectsV2Command({ Bucket, Prefix: "images/" }));
for (const obj of list.Contents ?? []) {
  console.log(obj.Key, obj.Size, obj.LastModified);
}

// Download
const file = await s3.send(new GetObjectCommand({ Bucket, Key: "images/logo.png" }));
const bytes = await file.Body.transformToByteArray();
console.log("downloaded", bytes.length, "bytes");

// Presigned download link, valid for 15 minutes
const url = await getSignedUrl(s3, new GetObjectCommand({ Bucket, Key: "images/logo.png" }), {
  expiresIn: 900,
});
console.log(url);

// Delete
await s3.send(new DeleteObjectCommand({ Bucket, Key: "images/logo.png" }));
```

Run it with `node --env-file=.env s3.mjs` (Node.js 20.6 or later).

**Large files.** `@aws-sdk/lib-storage` splits big files into a multipart upload and sends parts in parallel:

```js title="upload-large.mjs"
import { S3Client } from "@aws-sdk/client-s3";
import { Upload } from "@aws-sdk/lib-storage";
import { createReadStream } from "node:fs";

const s3 = new S3Client({
  region: "eu-central-2",
  endpoint: "https://s3.eu-central-2.cloider.com",
  requestChecksumCalculation: "WHEN_REQUIRED",
  responseChecksumValidation: "WHEN_REQUIRED",
});

const upload = new Upload({
  client: s3,
  params: {
    Bucket: "acme-backups",
    Key: "dumps/orders-2026-10-20.sql.gz",
    Body: createReadStream("./orders.sql.gz"),
  },
  partSize: 16 * 1024 * 1024, // 16 MiB parts
  queueSize: 4,               // 4 parts in parallel
});

upload.on("httpUploadProgress", (p) => console.log(p.loaded, "/", p.total));
await upload.done();
```

Install boto3 (version 1.36 or later knows the checksum settings):

```bash
pip install "boto3>=1.36"
```

```python title="s3.py"
import os

import boto3
from botocore.config import Config

s3 = boto3.client(
    "s3",
    endpoint_url="https://s3.eu-central-2.cloider.com",
    region_name="eu-central-2",
    aws_access_key_id=os.environ["AWS_ACCESS_KEY_ID"],
    aws_secret_access_key=os.environ["AWS_SECRET_ACCESS_KEY"],
    config=Config(
        signature_version="s3v4",
        s3={"addressing_style": "virtual"},  # "path" works too
        request_checksum_calculation="when_required",
        response_checksum_validation="when_required",
    ),
)

bucket = "acme-assets"

# Upload (multipart automatically for large files)
s3.upload_file(
    "logo.png", bucket, "images/logo.png",
    ExtraArgs={"ContentType": "image/png", "CacheControl": "public, max-age=86400"},
)

# Upload bytes directly
s3.put_object(Bucket=bucket, Key="notes/hello.txt", Body=b"Hello from Cloider", ContentType="text/plain")

# List every object under a prefix, across pages
paginator = s3.get_paginator("list_objects_v2")
for page in paginator.paginate(Bucket=bucket, Prefix="images/"):
    for obj in page.get("Contents", []):
        print(obj["Key"], obj["Size"], obj["LastModified"])

# Download
s3.download_file(bucket, "images/logo.png", "logo-copy.png")
body = s3.get_object(Bucket=bucket, Key="notes/hello.txt")["Body"].read()
print(body.decode())

# Presigned download link, valid for 15 minutes
url = s3.generate_presigned_url(
    "get_object",
    Params={"Bucket": bucket, "Key": "images/logo.png"},
    ExpiresIn=900,
)
print(url)

# Delete one object, then several at once
s3.delete_object(Bucket=bucket, Key="notes/hello.txt")
s3.delete_objects(
    Bucket=bucket,
    Delete={"Objects": [{"Key": "images/logo.png"}, {"Key": "images/old.png"}]},
)
```

```go title="main.go"
package main

import (
	"context"
	"fmt"
	"io"
	"log"
	"os"
	"time"

	"github.com/aws/aws-sdk-go-v2/aws"
	"github.com/aws/aws-sdk-go-v2/config"
	"github.com/aws/aws-sdk-go-v2/credentials"
	"github.com/aws/aws-sdk-go-v2/service/s3"
	"github.com/aws/aws-sdk-go-v2/service/s3/types"
)

const bucket = "acme-assets"

func main() {
	ctx := context.Background()

	cfg, err := config.LoadDefaultConfig(ctx,
		config.WithRegion("eu-central-2"),
		config.WithCredentialsProvider(credentials.NewStaticCredentialsProvider(
			os.Getenv("AWS_ACCESS_KEY_ID"), os.Getenv("AWS_SECRET_ACCESS_KEY"), "",
		)),
	)
	if err != nil {
		log.Fatal(err)
	}

	client := s3.NewFromConfig(cfg, func(o *s3.Options) {
		o.BaseEndpoint = aws.String("https://s3.eu-central-2.cloider.com")
		o.UsePathStyle = false // true works too
		o.RequestChecksumCalculation = aws.RequestChecksumCalculationWhenRequired
		o.ResponseChecksumValidation = aws.ResponseChecksumValidationWhenRequired
	})

	// Upload
	f, err := os.Open("logo.png")
	if err != nil {
		log.Fatal(err)
	}
	defer f.Close()
	_, err = client.PutObject(ctx, &s3.PutObjectInput{
		Bucket:      aws.String(bucket),
		Key:         aws.String("images/logo.png"),
		Body:        f,
		ContentType: aws.String("image/png"),
	})
	if err != nil {
		log.Fatal(err)
	}

	// List, across pages
	pages := s3.NewListObjectsV2Paginator(client, &s3.ListObjectsV2Input{
		Bucket: aws.String(bucket),
		Prefix: aws.String("images/"),
	})
	for pages.HasMorePages() {
		page, err := pages.NextPage(ctx)
		if err != nil {
			log.Fatal(err)
		}
		for _, obj := range page.Contents {
			fmt.Println(aws.ToString(obj.Key), aws.ToInt64(obj.Size))
		}
	}

	// Download
	out, err := client.GetObject(ctx, &s3.GetObjectInput{
		Bucket: aws.String(bucket),
		Key:    aws.String("images/logo.png"),
	})
	if err != nil {
		log.Fatal(err)
	}
	data, _ := io.ReadAll(out.Body)
	out.Body.Close()
	fmt.Println("downloaded", len(data), "bytes")

	// Presigned download link, valid for 15 minutes
	presigner := s3.NewPresignClient(client)
	req, err := presigner.PresignGetObject(ctx, &s3.GetObjectInput{
		Bucket: aws.String(bucket),
		Key:    aws.String("images/logo.png"),
	}, s3.WithPresignExpires(15*time.Minute))
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(req.URL)

	// Delete several objects in one request
	_, err = client.DeleteObjects(ctx, &s3.DeleteObjectsInput{
		Bucket: aws.String(bucket),
		Delete: &types.Delete{Objects: []types.ObjectIdentifier{
			{Key: aws.String("images/logo.png")},
		}},
	})
	if err != nil {
		log.Fatal(err)
	}
}
```

```java title="CloiderS3.java"
import java.net.URI;
import java.nio.file.Path;
import java.time.Duration;

import software.amazon.awssdk.auth.credentials.AwsBasicCredentials;
import software.amazon.awssdk.auth.credentials.StaticCredentialsProvider;
import software.amazon.awssdk.core.checksums.RequestChecksumCalculation;
import software.amazon.awssdk.core.checksums.ResponseChecksumValidation;
import software.amazon.awssdk.core.sync.RequestBody;
import software.amazon.awssdk.regions.Region;
import software.amazon.awssdk.services.s3.S3Client;
import software.amazon.awssdk.services.s3.model.S3Object;
import software.amazon.awssdk.services.s3.presigner.S3Presigner;

public class CloiderS3 {
    static final URI ENDPOINT = URI.create("https://s3.eu-central-2.cloider.com");
    static final Region REGION = Region.of("eu-central-2");
    static final String BUCKET = "acme-assets";

    public static void main(String[] args) {
        var credentials = StaticCredentialsProvider.create(AwsBasicCredentials.create(
                System.getenv("AWS_ACCESS_KEY_ID"), System.getenv("AWS_SECRET_ACCESS_KEY")));

        try (S3Client s3 = S3Client.builder()
                .region(REGION)
                .endpointOverride(ENDPOINT)
                .credentialsProvider(credentials)
                .forcePathStyle(false) // true works too
                .requestChecksumCalculation(RequestChecksumCalculation.WHEN_REQUIRED)
                .responseChecksumValidation(ResponseChecksumValidation.WHEN_REQUIRED)
                .build()) {

            // Upload
            s3.putObject(r -> r.bucket(BUCKET).key("images/logo.png").contentType("image/png"),
                    RequestBody.fromFile(Path.of("logo.png")));

            // List, across pages
            for (S3Object obj : s3.listObjectsV2Paginator(r -> r.bucket(BUCKET).prefix("images/")).contents()) {
                System.out.println(obj.key() + " " + obj.size());
            }

            // Download
            byte[] bytes = s3.getObjectAsBytes(r -> r.bucket(BUCKET).key("images/logo.png")).asByteArray();
            System.out.println("downloaded " + bytes.length + " bytes");

            // Presigned download link, valid for 15 minutes
            try (S3Presigner presigner = S3Presigner.builder()
                    .region(REGION)
                    .endpointOverride(ENDPOINT)
                    .credentialsProvider(credentials)
                    .build()) {
                var presigned = presigner.presignGetObject(p -> p
                        .signatureDuration(Duration.ofMinutes(15))
                        .getObjectRequest(r -> r.bucket(BUCKET).key("images/logo.png")));
                System.out.println(presigned.url());
            }

            // Delete
            s3.deleteObject(r -> r.bucket(BUCKET).key("images/logo.png"));
        }
    }
}
```

## Create a presigned URL {#create-a-presigned-url}

A presigned URL is a normal object URL with a signature in its query string. Anyone holding it can perform that one request (download or upload one object) until it expires, without having an access key. It is the standard way to:

- let users download private files (invoices, reports, purchased files) straight from the bucket,
- let browsers and mobile apps upload directly to the bucket, so large files don't pass through your server,
- hand a file to another service for a limited time.

The URL is signed locally by the SDK with your secret key: creating one doesn't call Cloider, and it can't be revoked individually. It stops working when it expires, or when the access key that signed it is deleted or loses access to the bucket. The longest validity S3 allows is 7 days (604800 seconds).

### Let a browser upload directly to the bucket

Your server creates a presigned **PUT** URL for one key and content type, and the browser sends the file to it. The dashboard's own file browser uploads files exactly this way.

```js title="server.mjs (Node.js, Express)"
import express from "express";
import { randomUUID } from "node:crypto";
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

const s3 = new S3Client({
  region: "eu-central-2",
  endpoint: "https://s3.eu-central-2.cloider.com",
  requestChecksumCalculation: "WHEN_REQUIRED",
  responseChecksumValidation: "WHEN_REQUIRED",
});

const app = express();
app.use(express.json());

app.post("/api/uploads", async (req, res) => {
  // Check here that the user may upload, and validate the type and size
  const { contentType } = req.body;
  const key = `uploads/${randomUUID()}`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: "acme-assets", Key: key, ContentType: contentType }),
    { expiresIn: 600 },
  );
  res.json({ url, key });
});

app.listen(3000);
```

```js title="browser.js"
async function upload(file) {
  const res = await fetch("/api/uploads", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ contentType: file.type || "application/octet-stream" }),
  });
  const { url, key } = await res.json();

  // The Content-Type must be the one the URL was signed for
  const put = await fetch(url, {
    method: "PUT",
    headers: { "Content-Type": file.type || "application/octet-stream" },
    body: file,
  });
  if (!put.ok) throw new Error(`Upload failed: ${put.status}`);
  return key;
}
```

Headers you sign (such as `Content-Type`) must be sent with exactly the same value, otherwise the storage answers `SignatureDoesNotMatch`.

### Force a download file name

Add a response header override to a presigned GET to make browsers download the file under a given name instead of displaying it:

```python
url = s3.generate_presigned_url(
    "get_object",
    Params={
        "Bucket": "acme-assets",
        "Key": "invoices/2026/0042.pdf",
        "ResponseContentDisposition": 'attachment; filename="invoice-0042.pdf"',
    },
    ExpiresIn=600,
)
```

## Common patterns

### Store the key, not the URL

Save an object's key (`uploads/3f2c...`) in your database rather than a full URL. You can then build the public URL (`https://acme-assets.s3.eu-central-2.cloider.com/<key>` on a [public bucket](/object-storage/public-and-private-buckets)) or create a fresh presigned URL whenever you need one.

### Reuse one client

Create the S3 client once when your app starts and reuse it. Each client keeps a pool of connections, and creating one per request pays a new TLS handshake every time.

### Set Content-Type on upload

Browsers display or download a file based on its `Content-Type`. Set it when uploading (`ContentType` in the SDKs), otherwise files are stored as `application/octet-stream` or whatever the SDK guesses.

### Handle versioned buckets

On a bucket with [versioning](/object-storage/versioning), `PutObject` returns a `VersionId`, `GetObject` and `DeleteObject` accept a `VersionId`, and `ListObjectVersions` lists the history. Deleting without a version id adds a delete marker instead of removing data.

## Troubleshooting

| Error | Fix |
| --- | --- |
| `XAmzContentSHA256Mismatch`, `InvalidRequest` or another error on every upload | Set the checksum calculation to `when_required` as in the examples. See [Checksum errors on upload](/object-storage/troubleshooting#checksum-errors) |
| `getaddrinfo ENOTFOUND acme-assets.s3.eu-central-2.amazonaws.com` or a similar AWS host | The endpoint isn't set, so the SDK talks to AWS |
| `SignatureDoesNotMatch` | Wrong secret key, a header sent differently from the presigned one, or the client signs for another host. See [Troubleshooting](/object-storage/troubleshooting#signaturedoesnotmatch) |
| `AccessDenied` | The key is read only, doesn't open the bucket, or a policy denies the action. See [Troubleshooting](/object-storage/troubleshooting#accessdenied) |
| `NoSuchKey` | No object under that key. Keys are case sensitive and have no leading `/` |
| `TypeError: Got an unexpected keyword argument 'request_checksum_calculation'` (Python) | boto3 is older than 1.36. Upgrade it, or remove the two checksum arguments (older versions don't send the new checksums) |

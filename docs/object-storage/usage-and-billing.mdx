Cloider bills object storage on one thing only: how much data your buckets store, per GB per month, charged by the hour. Requests, uploads, downloads and traffic are free. This page explains how the stored amount is measured, what counts toward it, how to see each bucket's usage and forecast, and how to keep the cost down.

## At a glance

| | |
| --- | --- |
| **Billed on** | Stored data, per GB per month, charged by the hour |
| **Measured** | Every few minutes, averaged over time |
| **Free** | Requests (PUT, GET, LIST, DELETE), uploads, downloads and traffic |
| **Counts toward storage** | Every file, every earlier version and delete marker kept by versioning, and parts of unfinished multipart uploads |
| **Price** | Shown on the **Create bucket** page, by `cloider pricing` and at [cloider.com/#pricing](https://cloider.com/#pricing) |
| **On the invoice** | An **Object Storage** line per bucket |
| **Where to see usage** | The bucket's **Usage** tab, the **Usage** page, `cloider bucket usage`, the API and MCP |

## How is object storage billed?

Cloider measures how many bytes each bucket stores every few minutes. You are charged for the average amount stored, at the storage price per GB per month, prorated to the hour. In practice:

- A bucket that stores 100 GB for a whole month costs 100 times the monthly price per GB.
- A bucket that stores 100 GB for 3 days, then is emptied, costs about 3 days' worth of 100 GB, about a tenth of the monthly amount.
- A file you upload and delete within the hour costs next to nothing.

There is no minimum size, no minimum storage duration, and no charge for an empty bucket. Requests and data transfer in both directions are free, so serving files from a [public bucket](/object-storage/public-and-private-buckets) doesn't add to the bill however often they are downloaded.

The sizes are measured in binary units: 1 GB in Cloider's usage figures is 1024³ bytes (1 GiB), which is how `cloider pricing` lists the price, per Gi.

### Find the current price

The **Create bucket** page shows the price per GB per month under the form. From the CLI:

```bash
cloider pricing
```

The `bucket` row, with the unit `storage per Gi`, is the price of one GiB stored for a month. Prices change, so check [cloider.com/#pricing](https://cloider.com/#pricing) or the [pricing reference](/reference/pricing) rather than copying an amount into your own documentation.

## What counts toward a bucket's size?

| Stored data | Counts? |
| --- | --- |
| Current files | Yes |
| Earlier versions kept by [versioning](/object-storage/versioning) | Yes |
| Delete markers | Yes (they are tiny) |
| Parts of multipart uploads that were never completed or aborted | Yes, until a [lifecycle rule](/object-storage/lifecycle-rules) or the tool aborts them |
| Empty folder markers created in the dashboard | Yes, zero bytes |
| Files you deleted from a bucket without versioning | No, from the next measurement |

The bucket's size shown in the dashboard and the CLI is the latest measurement, so it can lag a few minutes behind an upload or a delete.

## See a bucket's usage

<Tabs groupId="interface" queryString>
<TabItem value="dashboard" label="Dashboard" default>

1. Open **Buckets** in the sidebar and click the bucket.
2. Select the **Usage** tab.

It shows:

- **Avg. Stored (This Month)**: the average amount stored since the start of the month,
- **Stored Now**: the latest measurement,
- **Cost to Date (This Month)**,
- **Cost Forecast** for **This Month** and **Next Month**, if the bucket keeps storing what it stores now,
- daily charts of the average stored amount and the cost, with today's forecast on the last bar.

## How to reduce storage costs

- **Expire what you don't need.** A [lifecycle rule](/object-storage/lifecycle-rules) can delete temporary files, old logs and old backups automatically.
- **Limit version history.** Versioning keeps every overwritten and deleted file. Add a lifecycle rule with **Remove earlier versions after they've been replaced for** N days, so history is kept for as long as you need it and no longer.
- **Clean up unfinished uploads.** Interrupted multipart uploads leave invisible parts behind. A rule with **Clean up unfinished uploads after** 7 days removes them.
- **Compress before uploading.** Database dumps, logs and exports shrink a lot with `gzip` or `zstd`.
- **Delete buckets you don't use.** An empty bucket costs nothing, but forgotten data does. The **Size** column of the Buckets list shows where the data is.

## Billing and the Free plan

Buckets are billed like Cloider's other resources: the cost accrues as you go, appears on the [Usage](/account/usage) page, and is charged on your invoice under **Object Storage**. See the [billing model](/concepts/billing-model) and [Billing](/account/billing).

On the Free plan you can create one bucket. Accounts that are suspended can't create buckets until the account is back in good standing.
